# Zero Day Project

Welcome to **Zero Day**, my very first repository as a full‑stack engineer.  
This project is part of the **Linux Fundamentals** training, where I set up my local coding environment and learn the basics of working with Git, Ubuntu, and virtualization tools.

## Project Overview
- Learn how to configure a local Linux environment (WSL, Docker, or Vagrant).
- Practice essential Git commands (`clone`, `add`, `commit`, `push`).
- Understand core concepts: virtual machines, Ubuntu, and the `uname` command.

## Repository Purpose
This repository documents my journey in setting up and using a proper development environment outside of sandboxes, ensuring I can work locally and independently.
